# RM-14 — Shell/Termux CI engineering promises and behavioral audit

**Source basis:** exact clean post-RM-15 Git tree `b4768beb224c85bde63821b42983aea07b5f956a`. RM-13 and RM-13R1 remain **failed on device/unresolved**, and are deliberately not prerequisites.

**Merge window:** RM-14 + RM-16 reviewed. Separate overlays: shell dialect/tool/Termux validation vs remote dispatch idempotency/typed Actions UX. There is no shared new safety contract that warrants a combined source transaction.

**Architectural decision:** One immutable built-in `shell-ci` provider, integrated into existing V2 reviewed-provider registry, native DAG compilation, no shell subprocess wrapping, no new scheduler/dispatcher/trust store. Only source-reviewed, direct-argv jobs are hosted. Termux-only jobs remain native Android work; they cannot be exported as Ubuntu parity evidence.

**Known safety restrictions (not roadmap promise omissions):** source evaluation, arbitrary `sh -c`, dynamic shell expressions, privileged scripts, runtime download of test tools, unreviewed foreign platform configurations and hosted Termux-parity claims are forbidden. Zsh is not checked with ShellCheck and Ubuntu 24.04 shfmt 3.8 lacks Zsh parsing; use reviewed `zsh -n` instead. No false Zsh formatter support is claimed. Files that are not Git-tracked, absolute/traversal/symlink source paths or invalid UTF-8 are refused. An actual hosted shell/Zsh/Bats/ShellCheck run must use an appropriate preprovisioned runner; no claim of installer provisioning is made.
