## Separate external qualification gates (not engineering omissions)

- No remote GitHub Windows MSVC job was run in this local acceptance; MSVC compiler environment and the Windows Python/Git Bash bridge require independent hosted execution evidence.
- Meson native executable toolchain was not installed in this local environment. Its executable source/graph, JUnit adapter and artifact handling have source-bound and mocked-node tests, not a claimed real Meson SDK build.
- Signed release readiness, ABI compatibility with downstream consumers, authenticated GitHub results and external artifact provenance are not established by these local checks.

## Scope boundaries

Arbitrary CMake scripts, Meson plugins, network-sourced dependencies, unreviewed compiler versions, CPU ABIs outside admitted ELF/PE/Mach-O variants, compiler caches of mutable intermediate trees, PDB symbol claims, and cross-toolchain binary signing remain intentionally unsupported. Unsupported input must refuse rather than be counted as an unimplemented promised general interpreter.

## RM-13R1 — Termux ARM64 real-toolchain portability repair

The original RM-13 mandatory `test_real_native_gcc_binary_arch_and_symbols` and `test_real_static_archive_member_abi_refusal` compiled through the **host** GCC/G++ but asserted `elf-x86_64`. Real native Android/ARM64 GCC correctly emitted `elf-aarch64`; production ABI verification correctly blocked the false claim.

RM-13R1 derives the expected ABI from the actual compiler's `-dumpmachine` target (recognized x86_64/AMD64 and AArch64/ARM64 only), still inspects the produced ELF/`ar` bytes, rejects deliberately **opposite** architecture claims, and tests both ELF machine codes using adversarial fixture headers. Unsupported compiler targets fail the test rather than being silently skipped. The production ELF/PE/Mach-O and archive verifier code is unchanged.

Positive and negative proof: `test_compiler_target_mapping_and_refusals`, `test_both_elf_abis_reject_wrong_arch_without_native_cross_compiler`, `test_real_native_gcc_binary_arch_and_symbols`, `test_real_static_archive_member_abi_refusal`, plus inherited provider/DAG regressions. Device acceptance on Termux and real hosted MSVC remain independent evidence.
