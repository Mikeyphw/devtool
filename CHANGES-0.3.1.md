# Devtool 0.3.1

- Start the GTK desktop HUD in a compact summary mode by default.
- Add an Expand/Collapse control for metrics, recent events, actions, and debug details.
- Keep failures, warnings, target context, and live progress visible in compact mode.
- Re-anchor the window to the active monitor's top-right corner after resizing.
- Add `DEVTOOL_DESKTOP_HUD_START_EXPANDED=1` for users who prefer the full HUD at launch.
