# PRES-G2 — Interaction/reliability milestone gate

**Campaign position:** full-plan gate **54 of 70**.  
**Prerequisite:** qualified PRES-X08 plus the separate PRES-G2 interaction/reliability remediation overlay.  
**State:** prepared for native-Termux authoritative qualification.

## Gate window

This gate closes the interaction window after PRES-G1. It consumes the Textual substrate/default/hardening work, live control-center X08 adoption, and the pre-gate remediation discovered by the G2 audit. It does not add presentation runtime features.

The gate proves:

1. opening/refreshing the non-interactive control-center projection is repository read-only;
2. one source failure degrades one panel rather than terminating the control center;
3. selected-run identity remains stable while attention/list order changes;
4. Logs and Diagnostics remain distinct semantic surfaces;
5. every visible action is registry-backed by a canonical domain owner or has an explicit disabled reason;
6. Ctrl+C cancellation and q/Esc exit remain semantically distinct under completion/cancel races;
7. renderer terminal ownership restores on normal and interrupt paths;
8. Artifacts/Overlays/Workers/History/Run/Targets consume LIFE/DIST/RUN/EXO/EXEC/WRAP/TEST authorities rather than guessed shell commands;
9. navigation collisions fail qualification;
10. a fresh process produces the same bounded reference-only control-center contract without requiring Textual import in `--once` mode.

PRES remains a renderer/control client and does not own execution truth.
