# devtool 0.4.0

- Added the native Linux Qt 6/QML Devtool Control Center Phase 1.
- Added Overview, visual Run builder, local History, Settings, tray integration, and a detachable compact HUD.
- Added live state-file monitoring for `state.json`, `runs/*.json`, and `hud-active.json`.
- Added `--hud-mode control-center` to publish progress without spawning the GTK HUD.
- Added `devtool control-center` / `devtool gui` launcher commands.
- Added CMake install rules, desktop entry, icon, and Debian packaging metadata.
