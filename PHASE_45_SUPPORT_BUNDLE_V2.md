# Phase 45 - Support Bundle v2

Phase 45 expands the Android support bundle into a single bounded, redacted JSON debug cockpit export.

## Added sections

- `schema: 2` and `bundle_version: support_bundle_v2`
- `summary`
- `latest_probe_results`
- `debug_events`
- `run_command_trace`
- `bridge_roundtrip`
- `debug_workbench`
- `guided_fixes`
- `repo_doctor_results`
- `repo_execution_plan`
- `repo_path_resolution`
- `repo_queue_health`
- `recent_git_operations`
- `validation_health`
- `notification_health`
- `redaction_self_test`

## Privacy and safety

The bundle remains a JSON text artifact generated by `SupportBundle.build(Context)`.
Command text remains controlled by the existing Settings opt-in.
Raw log output is still disabled by default.
Exported debug events, trace details, operation summaries and validation errors are passed through `SupportRedactor` and truncated before inclusion.

The redaction self-test verifies bridge token, Authorization header, URL credentials, secret assignment and private-key-block redaction using a synthetic sample.

## Repository evidence

Repo evidence now has top-level sections instead of being buried only inside per-repo details:

- doctor result
- executor plan evidence from latest doctor run
- path-resolution status and safe repair actions
- queue/orphan recovery health
- recent Git operation trace

The phase does not add destructive recovery behavior. It exports evidence only.
