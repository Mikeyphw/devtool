# devtool 0.4.1

- Added `inspect-artifact` / `ia`, a machine-readable artifact inspection command exposing manifest metadata, inventory, bundle order and dependencies, validation results, previews, and optional repository-relative diffs.
- Devtool completion state now includes structured diagnostics for desktop inspection and history views.
- Devtool Control Center Phase 2 (0.2.0) adds an artifact inspector, bundle dependency view, inventory and diff browser, repository manager, multi-run dashboard, diagnostics browser, and desktop completion/failure notifications.
- Repository records persist branch, remote, cleanliness, last use, and active run counts.
- Active runs can be selected independently for compact HUD and diagnostic detail views.
